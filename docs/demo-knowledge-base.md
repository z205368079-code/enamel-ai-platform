# Demo Knowledge Base Plan

本文件只定义面试演示的合成知识库素材方向，不包含真实企业制度、售后承诺、价格或客户数据。

## 合成主题

- 珐琅锅首次使用与日常清洁
- 烤箱使用条件（以“请以产品标签和说明书为准”作为边界）
- 常见烹饪方式与火力建议
- 防刮、防磕碰和存放建议
- 合成 FAQ：材质、适用灶具、保养与售后咨询入口

## 入库与演示原则

- 每篇文档标记为“Demo synthetic content”，并在 MaxKB 应用中单独建测试知识库。
- 不上传真实客户聊天、订单、员工资料、未公开产品参数或公司政策。
- 当知识库没有可靠内容时，应用或 Gateway 应使用受控提示；不能由 Gateway 用通用 LLM 补全事实。
